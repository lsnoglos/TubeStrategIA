# 0.3 — piloto de sincronización y cuota central
Desplegar backend/Code.gs en Google Apps Script como aplicación web ejecutada por el propietario, con acceso de solicitudes externas; valida token y lista de prueba. Configurar propiedades de secuencia YOUTUBE_API_KEY y TEST_EMAILS (correos separados por coma). No poner claves en código. tokeninfo es solo para pruebas cerradas; migrar a verificación criptográfica de ID tokens con biblioteca JWT/Google antes de distribución pública.
Copiar URL HTTPS /exec a GitHub Actions > Variables > TUBESTRATEGIA_BACKEND_URL y ejecutar workflow. Sin URL, no se consulta YouTube.
Cada llamada search cuenta en el límite de 100 al día (Los Ángeles), compartido; búsqueda adaptativa puede consumir varias. Consultas de detalle y datos guardados siguen disponibles si sus cuotas lo permiten. YouTube aplica su cuota independientemente.
Drive solicita appdata, email y openid; verifica la cuenta. SQLite guarda consultas y filtros propios, no estadísticas externas. Si respaldo difiere, combinar, reemplazar con confirmación o dejar intacto. Sincroniza si respaldo no cambió desde última lectura. No hay escritura atómica entre dispositivos; evitar concurrencia en piloto. Métricas derivadas e historial extendido requieren aprobación. Reautorizar Drive o iniciar sesión si caducan tokens. Probar en dos dispositivos.
